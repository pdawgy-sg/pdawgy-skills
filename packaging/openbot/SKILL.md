# Dawg

Choose the installed skill that matches the request:

- `dawg-plan` for planning a feature, fix, or refactor.
- `dawg-init` for setting up coding-agent guidance in a repository.
- `dawg-architecture-maintain` for synchronizing architecture documentation with implemented behavior.
- `dawg-mr` for drafting a merge or pull request description from committed changes.
- `dawg-video-property-motion-edit` for producing a property motion reel.

Open the selected skill and follow its instructions. For planning and
initialization, resolve the active provider and the selected phases' pinned
delegation, Git, Java, and TLC prerequisites. On Claude Code, verify that the
session loads the separately installed native `pdawgy-skills` plugin and exposes
the required `pdawgy-skills:dawg-*` agent types. If a required capability is
missing, name it and stop the affected phase.
